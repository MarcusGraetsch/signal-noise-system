## How to import

1. Open [Spotlistr CSV-to-Spotify converter](https://www.spotlistr.com/static/search/playlist-converter/)
2. Upload a CSV file from `playlists/`
3. Spotlistr resolves URIs to your account and creates a new playlist
4. (Alternativ: programmatic via Spotify Web API + PKCE flow)

## Generation

All playlists are generated by `src/playlists.py` from the SQLite events table. Re-run to refresh.
